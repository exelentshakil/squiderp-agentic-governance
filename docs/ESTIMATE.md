### 2. Operating Principles & Deterministic Guardrails

1. **Deterministic Compiler-Level Enforcement**: C# Roslyn analyzers (`SquidErp.Roslyn.LedgerRule.cs`) throw compilation errors if ledger transactions bypass scopes. Rogue agents are blocked before human review is ever requested.
2. **SQL Server Multi-Tenant Partitioning**: Automated AST migration linters check that every database table and query contains mandatory `@TenantId` predicates and indexed clustered keys on `(TenantId, DocumentDate)`.
3. **3-Tier Multi-Agent Review Triad**: Parallel adversarial audit subagents (Concurrency Hunter, Domain Boundary Auditor, Ledger Guardian) achieve consensus in <2 seconds.
4. **Human-in-the-Loop Safeguards**: High-blast-radius financial mutations, database schema alterations, and sync protocol updates strictly escalate to Staff Architects.
5. **Strangler Fig Modernization**: Legacy .NET Framework 4.8 and complex SQL stored procedures are refactored into modern .NET 8 Clean Architecture with automated byte-for-byte regression characterization suites.
